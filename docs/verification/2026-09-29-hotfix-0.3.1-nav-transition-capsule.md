# 热修档：屏幕切换淡出效果移除 + 胶囊切换行为钉死（0.3.1）

日期：2026-09-29
版本：versionCode 6 / versionName 0.3.1
产物：`outputs/app-debug.apk`、`outputs/app-release-0.3.1.apk`

## 用户反馈与处置

### 反馈 2（本档主修）：切换界面不要淡出效果
- **根因**：`navigation-compose 2.8.5` 自 2.7.0 起为全部目的地默认 700ms **交叉淡入淡出**转场——
  首页↔书架 tab、设置子页、进出阅读器等所有"界面切换"都在慢速淡变。
- **修法**：`ui/Navigation.kt` 的 NavHost 四个过渡参数全部置 `EnterTransition.None / ExitTransition.None`
  （enter / exit / popEnter / popExit），全部界面切换变瞬切。
- 注：阅读器内工具栏呼出/收起的淡入滑动（ReaderScreen 的 AnimatedVisibility）不属于"界面切换"，
  保留原样；如也不要可再关。

### 反馈 1：阅读界面设置页的左右胶囊切换
- **行为测试证明现状可用**：新增 `app/src/test/.../ui/ReaderConfigCapsuleTest.kt`（Robolectric + 真实 Composable）：
  1. 「点击胶囊切换到对应分组」：点「字体」→ 出现"小说字体"；点「页面」→ 出现"阅读亮度"；点回「翻页模式」→ 复原。✅
  2. 「内容区横滑切换分组」：root 全宽左滑/右滑，分组往返。✅
- **健壮性加固**：顶部胶囊从 `Modifier.clip().clickable()` 改为 `Surface(onClick=…)`（全 App 目录/书签
  TabChip 同款写法，自带涟漪反馈与按钮语义），排除个别设备/输入法路径下不响应的嫌疑。
- **注意**：若用户设备打开配置页看到的仍是"整页上下滚动、没有胶囊"，说明装的是 **0.2.2 或更早**——
  胶囊分页版仅在 0.3.0 及以后存在；请安装 `app-release-0.3.1.apk`。
