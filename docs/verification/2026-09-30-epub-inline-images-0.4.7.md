# 0.4.7 验证档 —— EPUB 整页图片渲染（封面页 / 插图页进阅读流）

日期：2026-09-30
版本：**0.4.7 / versionCode 19**

## 需求（用户真机反馈，0.4.6 后追加）

"封面/插图不是空章节啊，是有插画和封面图的啊"——问题不应只是"跳过空章"，而要**把封面图与插画真正渲染出来**。

## 实现（B 方案第一步：整页图片渲染）

1. `NovelTextExtractor`
   - **文档内图片原位标记**：按文档顺序把 `<img>` / SVG `<image>` 标签替换为 `\u0001n\u0001` 标记（`extractAndMarkImages`），清洗后按标记拆分出**保序的 文本/图片 片段**（`splitMarkedLines`）；
   - 片段分配：纯图文档 → 一组整页图片（不生成章节标记）；图文混排文档 → 文本段落 + **按位置插入的图片组**（insertAtIndex = 该图片之前的段落数）；无图无文本 → 跳过；
   - 移除过时的"首文档含 `<img>` → 回退图片版"快速判定（封面用 `<img>` 的图文书不再被误判为漫画；纯图 EPUB 仍由"文本条目均未提取到内容"兜底回退）；
   - 安全限幅：单图 12MB / 单文档 64 张 / 单文档总 40MB。
2. `NovelPageSource`
   - 分页结构升级为 `NovelPage`（文本页 | 整页图片页，二者互斥）；图片组按插入点穿插进页流、每张图独立成页；
   - `renderPage`：图片页等比适合页面居中绘制（长边降采样解码；失败留透明底不崩）；
   - 「复制文字」对图片页返回空；进度锚点：图片页取插入点段落偏移（序列单调不降）。
3. `ArchiveFactory`：透传 `imageGroups`。

## 设计说明与已知边界

- 图片在流中的位置按"段落流插入点"近似（轻小说章内插画通常位于段落之间，近似准确；极端情况的段内图文会被规整到段边界）。
- 图片页为整页 fit 显示（与主流阅读器一致），不做文绕图等复杂排版。
- 图片章节不进入目录（目录仍为纯文本章节），图片页随翻页经过。
- **老书无需重扫**：阅读流图片在打开书时实时解析；仅书库封面需要走「刷新封面」。
