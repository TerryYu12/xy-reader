## 功能范围

点击书本（首页/书架/分组/分区列表四个入口）→ 先进详情页：封面、书名、格式/大小/页数、添加与阅读相对时间、目录卡片（当前章节高亮）、底部胶囊（从头开始 / 继续阅读 / 删除）。

- 点章节 → 直达该章起始页（含第一章 = 第 0 页，精确跳页不沿用进度）。
- 继续阅读 → 续读已存进度；从头开始 → 无视进度从 0 开始（reader 新增 `startFromBeginning` 参数，路由 `restart=true`）。
- 删除 → 二次确认，仅移除书库记录与书签，原文件保留；成功回列表。
- 收藏心形（右上有无同步切换）。
- 远程书（webdav:// / gdrive://）：详情页**不发起网络 IO**，目录区显示"远程书籍 · 进入阅读器后查看目录"。
- 本地无章节格式（PDF/扁平包）：目录区显示"共 N 页 · 无章节结构"；目录读取失败显示可读提示，不阻塞进入阅读。

## 已知限制（记录在案，不算缺陷）

- 远程书详情页不加载目录（设计取舍：避免详情页网络 IO；阅读器内有完整目录抽屉）。
- 详情页进入阅读器后，返回键回详情页（再返回回列表）——层级变化属预期。
- 目录卡片不显示"共 N 章"错误条数校验；压缩包章节按子文件夹名，重名文件夹会显示同名章节（行尾页码可区分）。
- release 混淆无法离机验证闪退风险（与前轮同），若闪退先换 debug 包并回日志。

## 下一轮实机清单（优先级从高到低）

1. 从首页点一本 CBZ：详情页目录正确（子文件夹分组）、当前章节高亮正确。
2. 点第二话 → 直达该话第一页；点第一话 → 从第 0 页开始（即使该书有进度）。
3. 继续阅读 → 回到上次进度；从头开始 → 从 0 开始且后续翻页进度正常。
4. 详情页收藏切换 → 返回列表一致；删除 → 二次确认、回列表、文件仍在。
5. 远程书（WebDAV/GDrive）详情页秒开不卡（无网络请求）、提示文案正确；进入阅读后目录抽屉可用。
6. 无章节 PDF：目录区文案正确；阅读正常。
7. 旋转屏幕 / 系统大字号：详情页布局不截断，底部胶囊不遮章节条目。
8. 体验确认：目录长度大时滚动顺畅；底部胶囊悬浮与列表滑动不打架。
