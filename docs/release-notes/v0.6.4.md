## 修复与稳定性优化

- **修复书源检测非法链接导致的协程中断与崩溃**：
  - 针对带有脏数据或非法 Host 字符（如含空格、连字符等）的书源 URL，增加协议与域名预校验及针对性异常捕获，判定为不可用链接并展示具体原因，杜绝底层网络库抛出未捕获 `IllegalArgumentException` 导致整批检测中断或应用崩溃。
  - 并发检测升级为独立异常隔离架构（`supervisorScope`），单条异常源故障完全隔离，确保千条书源批量检测稳定跑完全程。
- **重构书源存储链路，解决大批量源（数千条）内存溢出（OOM）**：
  - 全面引入 Android 原生流式 `JsonWriter` / `JsonReader`，彻底消除序列化时在内存中构建上万个 `JSONObject`/`JSONArray` 节点树的巨大内存驻留。
  - 自动过滤存储中的冗余空规则字段，将数千条书源持久化体积压缩 60% 以上，从根本上解决 37MB 连续内存分配引发的 OOM。
  - `<application>` 开启 `android:largeHeap="true"`，为多图阅读与超大书源合集管理提供充裕的内存堆空间。
  - 书源管理界面检测结果改用 Compose 快照状态映射原地更新，消除批量检测过程中数百万次 Map 拷贝产生的 GC 抖动。
