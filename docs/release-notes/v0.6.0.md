## 新功能

- **在线书源引擎**：支持导入 Legado 兼容书源（XPath / 正则 / JSONPath / JS 规则沙箱），可搜索、抓取整本并离线阅读。主仓不内置任何书源，导入入口在「仓库 → 在线书源」。
- **仓库页**：底部导航新增「仓库」，集中管理 本地仓库 / 远程仓库 / Google Drive / 在线书源 四个来源入口。
- **木质书柜**：书架改为分层木质陈列，每个分组独占一层，封面与书脊混排、同层可横向滑动；点书脊先展开成封面，再点才打开书籍，任一时刻最多一本展开。
- **阅读统计分页**：拆为 详情 / 日历 / 成就 三个标签——详情保留七项累计数据并新增「按书累计时长」竖向柱状排行；日历为最近 30 天 3×10 矩阵；成就为连续打卡徽章与封面边框。
- **书籍详情页「书签」标签**：列出这本书的全部书签（页码 + 时间），点击直接跳到对应页，可删除。
- **统一下载底座**：书籍下载、后台抓取与更新包下载共用一套管理器。

## 优化

- 界面按新设计规范重构：日间玫瑰红配色（#F6F7FA 背景 / #FF4F8B 强调色），保留深色模式与强调色设置，不覆盖既有用户偏好。
- 首页：顶栏改为「搜索｜日夜切换｜设置」；超长书名自动滚动播放；分组胶囊收窄并去掉数量，最左固定「全部」、最右固定「分组管理」。
- 书架页精简：只保留 全部 / 收藏 / 历史 / 书签 四个入口小卡片与木质书柜；分组管理合并到书柜右上角。
- 删除本地文件改为两道确认，第二道确认按钮位置与第一道互换，避免连点误删。
- 切换页面性能：木纹改用 GPU 平铺着色器（不再逐帧绘制）、书库数据增加进程内快照缓存、切换时不再出现整页重建的偶发长帧。

## 修复

- 修复切页时背景露白/露黑造成的闪烁（窗口背景改为跟随主题）。
- 修复书籍标题被三点菜单挤压、格式角标与阅读进度未对齐。
- 修复阅读时长按书籍统计缺失导致排行榜空白的问题（数据库迁移 1→9，兼容旧数据）。
