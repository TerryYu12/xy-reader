## 新增与体验优化

- **书源搜索结果相关性智能过滤与精准排序**：
  - 自动识别并过滤搜索结果页面底部、侧边栏中夹带的“猜你喜欢”、“热门排行”等无关书籍推荐，彻底解决搜索结果与关键词风马牛不相及的问题。
  - 搜索结果按相关度置顶展现：完全匹配书名优先，其次为书名包含、作者匹配。

## 修复与稳定性优化

- **全面支持 Legado 书源标准 POST 搜索与请求参数拆分**：
  - 支持 `searchUrl,{"method":"POST","body":"...","charset":"..."}` 高级书源语法，自动组装 Form 表单与 JSON 请求体，使社区大量依赖 POST 接口的书源恢复可用。
  - 完善 `{{source.key}}`、`{{source.bookSourceUrl}}`、`{{baseUrl}}` 等书源常用环境变量模板展开。
- **全链路 GBK / GB2312 字符集自动识别与编码适配**：
  - 发起搜索时根据书源配置对关键词与请求体采用对应字符集编码，彻底解决老牌小说站因收到 UTF-8 乱码而退回全站推荐榜的问题。
  - 响应内容通过 OkHttp 字节流自适应识别页面编码（书源显式配置 → Header Content-Type → HTML meta 嗅探），杜绝网页乱码与解析失败。
- **相对路径与自适应协议 URL 补全**：
  - 针对以 `/` 或相对文件名开头的 `searchUrl` 与正文/目录 URL，自动补全域名协议；修复 `//cdn.xxx.com` 自适应协议链接拼接触发非法 URL 异常的缺陷。
