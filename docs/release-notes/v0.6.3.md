## 新功能

- **书源可用性批量检测**：
  - 在「仓库 → 在线书源」管理页新增「检测可用性」能力，支持受控并发（8 线程）渐进式批量探测书源站点连通性与网络响应耗时，支持随时中断并保留已检测结果。
  - 检测过程中动态展示全局进度条与当前检测源名称；完成后展示可用与不可用书源统计。
  - 每条书源卡片直观呈现可用性徽标（绿色毫秒延迟 / 红色不可用原因，包括连接超时、HTTP 状态码、域名解析失败等）。
- **一键选中不可用与批量删除**：
  - 检测出不可用源后，提供「一键选中不可用」快捷操作，快速勾选所有失效书源并唤起批量操作面板。
  - 支持多选全选/全不选与批量删除二次确认，一键清除冗余死源，已下载本地书籍不受任何影响。
- **单书源快速测速**：
  - 每条书源卡片支持独立点击「检测」，便于单源调整规则或更换网络后快速重试。

## 优化

- **搜索结果来源置顶展示**：书源搜索页优先置顶展示已检索出有效书籍的书源卡片，未检索到或失败的书源自动折叠沉底，找书更高效。
