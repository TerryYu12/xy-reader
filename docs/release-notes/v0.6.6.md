## 新增与体验优化

- **搜索结果严格相关性过滤与精准排序**：
  - 自动识别并过滤搜索结果页面底部、侧边栏中夹带的“猜你喜欢”、“热门排行”等无关书籍推荐，彻底解决搜索结果与关键词无关的问题。
  - 搜索结果按相关度置顶展现：完全匹配书名优先，其次为书名包含、作者匹配。

## 修复与稳定性优化

- **Legado 书源规则解析引擎重大升级**：
  - 深度支持常规 HTML 标签与 CSS 选择器（如 `h4 a`, `.title a`, `a.0`、裸标签直接提取等），解决国内大量主流书源因旧规则引擎无法识别 CSS 标签而判定书籍无效、导致“搜不到/全错误”的问题。
  - 智能属性兜底提取：当规则节点未显式声明属性时，链接规则自动提取 `a@href`，封面规则自动提取 `img@src`，书名与作者自动提取文本内容。
  - 增强 JSONPath 遍历与通配提取（如 `$.data[*]`、`data.*`）。
- **请求链路防 403 拦截与性能飞跃**：
  - OkHttp 请求自动补齐标准桌面浏览器 `User-Agent`，彻底避免各大盗贴与网络小说站因 OkHttp 默认特征直接返回 `403 Forbidden`。
  - 采用 10 并发协程 Channel 消费架构与 `supervisorScope`，针对大批量书源（数百甚至上千个源）并发极速搜索，杜绝单线程串行超时卡死。
  - 完善单书 302 重定向直接命中书籍详情页的提取支持。
